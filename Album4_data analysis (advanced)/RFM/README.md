# Customer Segmentation with RFM Analysis

## Objective
Segment users of an e-commerce store using the **RFM model** (Recency, Frequency, Monetary) to design targeted strategies for different customer groups.

## Process
1. Extract R, F, and M data.  
2. Perform descriptive analysis and apply data binning.  
3. Label users with segmentation results.  

- **Data Source**: Provided in the project folder
