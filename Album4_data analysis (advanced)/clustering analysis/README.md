# Customer Segmentation with K-Means Clustering

## Objective
Apply the **K-Means algorithm** to classify e-commerce users into K groups for strategy design, ensuring an objective and data-driven segmentation process.

## Process
1. Normalize the dataset.  
2. Use the **elbow method** to determine the optimal value of K.  
3. Visualize the results with a 3D scatter plot to observe the characteristics of each user group.  

- **Data Source**: Provided in the project folder
