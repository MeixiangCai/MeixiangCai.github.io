# Employee Attrition Prediction with Decision Tree

## Objective
Use a **decision tree model** to predict whether an employee will leave the company and evaluate the model’s performance.

## Process
1. Prepare the dataset, build a decision tree model, evaluate classification accuracy, and predict employee attrition.  
2. Plot the **ROC curve** and calculate the **AUC score** to measure model performance.  
3. Apply **GridSearch** to perform hyperparameter tuning and improve the model.  

- **Data Source**: Provided in the project folder
