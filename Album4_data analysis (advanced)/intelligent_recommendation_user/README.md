# Intelligent Movie Recommendation System (User-Based Collaborative Filtering)

## Objective
Build a movie recommendation system based on user-based collaborative filtering. The system identifies similar users using correlation analysis and recommends movies that the target user is most likely to be interested in.

## Process
1. Merge the movie list with the ratings list.  
2. Construct an item–user pivot table.  
3. Identify similar users using the Pearson correlation coefficient.  
4. Retrieve movies that the target user may be interested in.  

- **Data Source**: Provided in the project folder
