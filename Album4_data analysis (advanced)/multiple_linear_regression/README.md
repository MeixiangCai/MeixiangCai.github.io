# Multiple Linear Regression Projects

This folder contains two Python scripts demonstrating advanced applications of multiple linear regression:
1. `multiple_linear_regression.py` – Predicting new users with multiple linear regression.  
2. `multicollinearity_and_overfitting.py` – Addressing multicollinearity and overfitting in regression models.  

# Predicting New Users with Multiple Linear Regression

## File
`multiple_linear_regression.py`

## Objective
Build a **multiple linear regression model** to analyze the impact of several factors on the number of new users and predict future data.

## Process
1. Plot multivariate scatter plots and a correlation heatmap to identify which factors (independent variables) influence new user growth.  
2. Construct a multiple linear regression model, validate it, and use it for prediction.  

- **Data Source**: Provided in the project folder

# Addressing Multicollinearity and Overfitting in Multiple Linear Regression

## File
`multicollinearity_and_overfitting.py`

## Objective
Resolve common issues in multiple linear regression, including **multicollinearity** and **overfitting**, to improve model reliability and interpretability.

## Process
1. Use the **Variance Inflation Factor (VIF)** method to check multicollinearity among independent variables.  
2. Split the dataset into training and testing sets to mitigate overfitting.  
3. Manually remove independent variables to address multicollinearity.  

- **Data Source**: Provided in the project folder
