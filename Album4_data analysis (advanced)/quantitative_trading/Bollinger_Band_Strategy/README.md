# Bollinger Bands Trading Strategy

## Objective
Build a **quantitative trading model** using the Bollinger Bands strategy, which helps avoid the lag effect commonly seen in single or dual moving average strategies.

## Process
1. Plot candlestick charts.  
2. Plot the **Middle Band** (moving average), **Upper Band**, and **Lower Band**.  
3. Define **buy signals** (price touches or falls below the Lower Band) and **sell signals** (price touches or breaks above the Upper Band), then conduct backtesting.  
4. Continuously adjust and optimize the standard deviation parameter based on backtest results.  

- **Data Source**: Provided in the project folder
