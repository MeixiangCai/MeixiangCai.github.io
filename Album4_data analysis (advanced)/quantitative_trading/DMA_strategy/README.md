# Dual Moving Average Trading Strategy

## Objective
Build a **quantitative trading model** using a dual moving average strategy, which provides improved responsiveness to market changes compared to a single moving average approach.

## Process
1. Plot candlestick charts and dual moving average lines.  
2. Identify **golden crosses** and **death crosses**.  
3. Simulate trading with an initial capital of 100,000 and calculate the return.  

- **Data Source**: Provided in the project folder
