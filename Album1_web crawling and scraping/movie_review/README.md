# Douban Movie Reviews Scraper - "Ne Zha"

## Objective
Scrape all short reviews of the hit movie *"Ne Zha"* from Douban, then generate a word cloud of the most frequent terms to provide an overview of audience feedback.

- **Website**: [Douban - Ne Zha](https://movie.douban.com/subject/34780991/?from=showing)  
- The generated word cloud in `.html` format is included in the folder as a reference.  
- Link to the demo video (created by me) on Google Drive: https://drive.google.com/file/d/1Lqr5XWmY_7iPs7ozr8H0vdwlrzBow4OH/view?usp=share_link  

## Features
- Automated web scraping of movie short reviews from Douban.  
- Word cloud generation based on term frequency.  
- Export results in HTML for visualization.
