# Scraping Movie Posters from Douban

## Objective
Batch download high-resolution posters of the **Top 250 movies** from Douban.

## Process
1. Send requests to retrieve webpage content.  
2. Parse the HTML to extract movie information.  
3. Extract poster details for each movie and download the images.  

- website: "https://movie.douban.com/top250?start="
- For practice, only the first page (Top 25 movies) is scraped. The resulting posters are provided in the folder as references.
