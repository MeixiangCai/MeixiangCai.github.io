# Automatic Speech Recognition (ASR)

## Objective
Use **AipSpeech** to generate subtitles for video files through speech-to-text conversion.

## Process
1. Define functions for speech-to-text conversion and audio file reading.  
2. Extract audio from the video file.  
3. Configure parameters for the audio file and create a list of audio segments.  
4. Apply the defined functions to batch process speech-to-text conversion.  
5. Define functions for subtitle file creation and writing.  
6. Iterate through the list to batch-generate **.srt** subtitle files.  

- Test video and generated subtitle files are provided as references.
