# Sentiment Analysis with Baidu NLP API

## Objective
Create an NLP client that leverages **Baidu AIP** to directly determine the sentiment polarity (positive or negative) of a given text.

## Process
1. Use **AipNlp** to analyze the test sentence: “他这个人真是太下头了”.  
2. Obtain the sentiment result (positive, neutral, or negative).
