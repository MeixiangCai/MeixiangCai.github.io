# Face Recognition with Mask Detection

## Objective
Use **AipFace** to automatically detect whether a person in an image is wearing a mask, and display the detection results.

## Process
1. Convert the image into a string format.  
2. Apply the **detect** interface from **AipFace** for face detection.  
3. Create a canvas from the image to display detection results.  
4. Analyze the detection output, highlight the facial region, and overlay text showing the result.  

- The original image and the processed image are provided in the folder as references.
