# E-commerce Sales and Page Views Analysis

### Objective
Analyze sales and page view data of an e-commerce store to explore potential causes of declining sales, using concatenation and merging operations in Python.

### Requirements
1. Concatenate the 2019 and 2020 sales data tables vertically.  
2. Merge the combined sales data with the page view data table.  
3. Create a 6-panel subplot, each displaying a dual-axis overlay chart per product:  
   - **Bar chart (left Y-axis):** Page views (exposure)  
   - **Line chart (right Y-axis):** Conversion rate (sales/views)
