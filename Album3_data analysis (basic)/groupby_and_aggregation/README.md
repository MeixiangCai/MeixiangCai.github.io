# Mall Sales Data Analysis

## Objective
Analyze mall sales data to explore potential causes of revenue decline, using group-by operations and aggregation techniques in Python.

## Requirements
1. Plot a line chart showing the relationship between daily sales revenue and date.  
2. After resampling, plot a line chart showing the relationship between monthly sales revenue and date.  
3. Use a 4-panel subplot to display sales trends of each product category over time.  
4. Generate a 100% stacked bar chart showing the monthly revenue distribution by product category.  

- **Data Source**: Provided in the project folder
