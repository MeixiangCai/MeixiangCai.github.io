# Bookstore Sales Data Visualization

### Objective
The final step of this analysis is data visualization. The project creates the following visualizations using the provided datasets:

1. **Line & Bar Chart**: Monthly sales trend of the bookstore from August 2019 to July 2020  
   - Line chart: Overall sales trend  
   - Bar chart: Monthly sales values  

2. **Scatter Plot**: Relationship between sales volume and advertising expenditure  

3. **Dual-Axis Overlay Chart**:  
   - Bar chart (left Y-axis): Exposure  
   - Line chart (right Y-axis): Conversion rate  

4. **Clustered Column Chart**: Monthly sales trends by floor in the bookstore  

5. **100% Stacked Column Chart**: Monthly sales percentage distribution by floor  

6. **Multi-Panel Subplot**:  
   - Top: Line chart of sales over time  
   - Bottom: Clustered column chart of sales by floor over time  

- **Datasets**: Provided in the project folder
