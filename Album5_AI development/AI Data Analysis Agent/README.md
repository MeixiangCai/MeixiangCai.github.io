# AI Data Analysis Agent

## Objective
Build an AI agent that automatically analyzes data, generates visualizations, produces structured report, and automatically sends an analysis report via email to designated recipients.

## Process
	1.	Load CSV data with Pandas
	2.	Analyze data using a LangChain dataframe agent
	3.	Generate structured JSON for visualization
	4.	Render charts with Matplotlib
	5.	Aggregate results into an analysis log
	6.	Generate an HTML report using LLM
	7.	Send the report via email 

- The file to be analyzed has been provided;
- The prompt template has also been provided.
