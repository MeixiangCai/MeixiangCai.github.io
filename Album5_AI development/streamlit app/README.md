# Economist Study Assistant

## Objective
Help users learn and understand The Economist content with AI explanations.

## Process
	1.	User selects topic and explanation style.
	2.	Input question or expression in chat interface.
	3.	AI generates context-aware response using LangChain and OpenAI model.
	4.	Conversation history is maintained for continuity.
	
- The style prompt template has been provided.
- The deployed website on streamlit: https://chatbot-economist.streamlit.app/
