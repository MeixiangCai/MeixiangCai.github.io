# AI Chinese-to-Tagalog Translator

## Objective
Translate Chinese text into Tagalog using OpenAI API

## Process
	1.  Set up the OpenAI client with your API key and base URL.
	2.	Define a system prompt specifying the AI as a Tagalog translation expert.
	3.	Send Chinese text messages via client.chat.completions.create.
	4.	Receive and print the Tagalog translation.
